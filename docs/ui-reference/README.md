# UI Reference

本目录用于存放华哥节点管理后台的 UI 参考图。

这些图片是后台界面重构的视觉参考，不要求 100% 像素级复刻，但整体风格、布局和交互逻辑必须保持一致。

## 项目定位

这个后台不是给客户使用，也不是商业 SaaS 平台。

这是华哥自己内部使用的节点采集、测试、整理、导出和领取管理后台。

后台只给管理员自己操作，要求：

- 操作简单
- 页面清楚
- 适合小白使用
- 适合录屏展示
- 看起来专业、干净、舒服
- 不要所有功能堆在一个页面

## UI 风格要求

整体风格参考本目录内所有 PNG 图片：

- 左侧固定菜单
- 右侧分模块页面
- 浅色背景
- 白色卡片
- 绿色作为主色
- 圆角卡片
- 清晰表格
- 留白充足
- 按钮状态明显
- 页面不要拥挤
- 不要花哨
- 适合录屏视频展示

## 菜单页面要求

左侧菜单必须对应独立页面：

1. 首页仪表盘
2. 采集任务
3. 节点池
4. 测试记录
5. 节点包
6. 领取页
7. 统计数据
8. 反馈数据
9. 系统设置
10. 运行日志

不要把所有功能堆在首页。

首页只做总览，其他功能进入对应页面操作。

## 交互要求

所有按钮点击后必须有明确反馈：

- loading 状态
- 成功提示
- 失败提示
- 错误原因

不允许出现“按钮点击后没有任何反应”的情况。

## 领取页特殊要求

领取页是给粉丝输入口令领取节点包的公开页面。

公开领取页必须极简，只保留：

- 标题
- 简单说明
- 口令输入框
- 验证并领取按钮
- 下载按钮
- 必要提示

公开领取页不能展示任何后台内部信息，包括但不限于：

- 节点数量
- 节点来源
- 采集来源
- 测试数据
- 后台统计
- 服务器信息
- IP
- UUID
- Token
- 日志
- 失败原因
- 内部批次细节

粉丝只需要能领取节点包，不需要看到后台逻辑。
