# Changelog

## v0.6.0 - 2026-05-23

### Added

- 添加后端公开视频模式设置。
- 添加敏感信息脱敏工具，隐藏节点链接、Token、UUID 和完整 IPv4。
- 节点池、来源缓存、运行日志接口在公开视频模式下脱敏。
- 公开下载接口增加按批次和 IP 哈希的分钟级限速。
- `.env.example` 添加 `DOWNLOAD_RATE_LIMIT_PER_MINUTE`。

### Changed

- 仪表盘版本更新为 v0.6.0。
- 公开视频模式开关会写入后端设置，刷新后仍生效。
- 按用户要求，不主动 push GitHub，只本地提交，等待明确推送指令。

## v0.5.0 - 2026-05-23

### Added

- 添加公开领取页路由 `/p/:slug`。
- 添加公开批次信息 API。
- 添加口令验证 API，正确口令后设置短时解锁 Cookie。
- 添加节点包下载 API，只有口令验证后才能下载。
- 添加访问、口令尝试、口令正确、口令错误、解锁、下载、反馈事件统计。
- 添加来源平台参数记录，支持 `?from=...`。
- 添加公开反馈入口，支持地区、运营商、设备、使用软件、是否可用、备注。

### Changed

- 仪表盘版本更新为 v0.5.0。
- 按用户要求，不主动 push GitHub，只本地提交，等待明确推送指令。

## v0.4.0 - 2026-05-23

### Added

- 添加导出批次服务。
- 支持自定义导出数量，默认 10 条。
- 支持按最大/最小延迟范围筛选导出节点。
- 默认导出测试通过、未导出、后台初筛延迟最低的节点。
- 生成纯节点文本文件 `候选节点.txt`。
- 生成 `v2rayN导入说明.txt`、`使用说明.txt`、`免责声明.txt`、`反馈模板.txt`。
- 使用管理员手动口令生成加密 zip 节点包。
- 添加导出批次 API 和后台导出表单。
- Docker runtime 镜像安装 `zip` 命令。

### Changed

- 仪表盘版本更新为 v0.4.0。
- 导出后的节点状态更新为 `exported`，并记录所属批次。

## v0.3.0 - 2026-05-23

### Added

- 添加基础节点端点解析，支持从常见节点链接提取 host/port。
- 添加 TCP 连通性初筛，记录“后台初筛延迟”。
- 添加测试批次表和节点级测试结果表。
- 添加测试失败原因记录。
- 添加测试任务 API 和后台触发入口。
- 添加候选节点池延迟分布统计。
- 添加节点池后端筛选：协议、状态、来源类型、延迟范围、是否已导出。

### Changed

- 仪表盘版本更新为 v0.3.0。
- 失败节点默认不进入候选池，只保留测试失败记录。

## v0.2.0 - 2026-05-23

### Added

- 添加公开来源发现模块。
- 添加 GitHub 公开仓库候选文件发现。
- 添加公开 URL 种子采集配置 `PUBLIC_SOURCE_SEEDS`。
- 添加公开文本抓取、大小限制、请求超时、失败重试。
- 添加来源缓存、来源冷却、失败降频。
- 添加节点链接提取和协议识别，支持 `vmess`、`vless`、`trojan`、`ss`、`ssr`、`hysteria2`、`hy2`、`tuic`。
- 添加节点完全去重入库。
- 添加采集任务历史和来源级采集记录。
- 添加后台采集触发、来源缓存、采集历史的基础页面。

### Changed

- 仪表盘版本更新为 v0.2.0。
- 重写前端主入口，修复 Windows 环境下中文编码损坏导致的 JSX 风险。
