# Changelog

## v1.1.1 - 2026-05-26

- 修复领取页管理复制链接无反馈问题：补齐 `navigator.clipboard` 失败时的 HTTP fallback（`textarea + execCommand('copy')`）与手动复制输入框。
- 新增订阅活动发布前检查接口：`POST /api/subscriptions/:id/preflight`，检查项改为订阅池语义（缓存、输出节点、真实可用池、延迟劣化、过期状态）。
- 领取页管理页补齐订阅主流程操作：可复制领取页链接、raw 订阅链接、base64 订阅链接，并保留旧节点包批次为备用。
- 修正订阅模式发布前检查文案，移除“重新生成节点包”等旧节点包残留提示。

## v1.1.0 - 2026-05-26

- 新增自动节点订阅池主流程：每期 YouTube 视频可创建一个订阅活动，活动拥有固定截止时间、领取页 slug 和订阅 token。
- 新增 raw / base64 通用订阅输出：`/sub/:token/raw` 与 `/sub/:token/base64` 只读取缓存内容，不触发实时采集或 Xray 检测。
- 新增后台“订阅管理”页面，支持创建订阅活动、重建订阅输出池、执行健康检查和刷新订阅缓存。
- 新增后台自动订阅健康检查定时任务：默认每 300 秒扫描已发布活动，替换失效、超出淘汰延迟或真实检测过旧节点，并刷新订阅缓存。
- 新增订阅 token 活跃 IP 风险标记：超过 5/10/30 个活跃 IP 哈希时标记低/中/高风险。
- 公开领取页主交付方式改为订阅链接；ZIP 节点包保留为后台备用导出，不再作为粉丝端主流程。
- 新增订阅缓存目录与订阅默认配置：默认有效期 15 天、默认输出 10 条、缓存响应 300 秒。
- 反馈数据新增订阅活动关联字段，粉丝反馈可关联订阅活动和订阅 token。

## v1.0.1 - 2026-05-24

- 修复 Xray-core 全量真实检测队列：按批次低并发持续检测未检测候选节点，并展示全量累计统计。
- 修复 Xray 状态提示：已启用时显示真实代理检测状态，未启用时才提示配置内核路径。
- 修复节点包 ZIP 兼容性：领取页继续口令验证，ZIP 文件本身不再加密，根目录保持 ASCII 文件名。
