# Security

## 后台登录安全

- 管理后台必须登录后访问。
- 首次管理员账号由 `.env` 设置。
- 数据库已有管理员后，不再使用环境变量覆盖密码。
- 密码使用 bcrypt 哈希存储，不能明文保存。
- 登录失败次数达到阈值后会临时锁定。
- Session 使用 HttpOnly Cookie，支持过期。

## `.env` 安全

- 真实 `.env` 禁止提交到 GitHub。
- 生产环境必须更换默认密码和 `SESSION_SECRET`。
- `.env.example` 只能保存模板值。

## GitHub 禁止提交内容

禁止提交：

- 真实 `.env`
- Token、API Key、账号密码
- SQLite 数据库
- 采集到的节点
- 测试通过的节点
- 订阅文件
- 节点包和 zip 文件
- 运行日志
- 领取统计和反馈数据
- 真实后台配置

允许提交：

- 源码
- README 和 docs 文档
- Docker Compose 配置模板
- `.env.example`
- `.gitignore`

## 节点数据保护

- 节点内容只保存在 VPS 运行数据库中。
- 导出的节点包只保存在运行数据目录。
- GitHub 仓库只保存软件开发文件，不保存运行数据。

## 日志脱敏

后续版本必须保证日志不输出：

- 完整节点链接
- 完整 IP
- UUID
- 密码
- Token
- 私密来源 URL
- 管理员账号密码

## 公开视频模式

v0.1.0 已有前端开关雏形。v0.6.0 需要完整实现：

- 隐藏管理员账号
- 隐藏完整节点链接
- 隐藏完整 IP / UUID / 密码 / Token
- 隐藏敏感来源
- 隐藏后台路径和服务器信息
- 仅展示数量、协议类型、延迟数字、状态、批次编号和延迟分布

## 采集限速

v0.2.0 已加入基础限制：

- `COLLECT_MAX_CONCURRENCY` 控制并发，默认 2。
- `COLLECT_DAILY_MAX_RUNS` 控制每日最大采集次数，默认 6。
- `COLLECT_MIN_INTERVAL_MINUTES` 控制同一来源重复访问间隔，默认 60 分钟。
- `HTTP_TIMEOUT_SECONDS` 控制请求超时。
- `COLLECT_MAX_BYTES` 控制单个来源最大读取大小。
- 失败来源会进入更长冷却时间。

采集功能必须继续遵守：

- 只采集公开内容
- 不访问私人仓库
- 不绕过登录
- 不抓取私人数据
- 不高频请求
- 不全网乱扫
- 限制并发
- 失败重试有限
- 失败来源自动降频
- 缓存已发现来源

## 下载限速

公开领取页后续需要：

- 限制下载频率
- 记录下载事件
- 防止同一来源短时间大量请求
- 不直接展示完整节点
- 只有口令正确后才能下载加密 zip 包

## VPS 流量安全

系统本质是公开资源整理和基础初筛，不是公开代理服务：

- 不开放代理端口给公网
- 测试相关临时服务只允许绑定 `127.0.0.1`
- 测试完成后关闭临时进程
- 不做大流量压测
- 不上传节点到 GitHub
