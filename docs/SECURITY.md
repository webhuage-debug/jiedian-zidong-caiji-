# Security

## 2026-05-26 订阅池安全边界

- 粉丝端主交付方式改为订阅链接，ZIP 仅作为后台备用导出；公开领取页输入视频口令后才显示 raw/base64 订阅链接。
- 订阅 token 必须随机生成，禁止使用自增 ID；录屏模式下完整 token、slug、后台地址、端口和订阅链接必须脱敏显示。
- 订阅访问接口 `/sub/:token/raw` 与 `/sub/:token/base64` 只读取缓存内容，不触发实时采集、实时 Xray 检测、实时全量筛选或复杂数据库写入。
- 订阅健康检查由后台定时任务执行，默认每 300 秒扫描需要维护的已发布活动；粉丝访问订阅链接不会触发健康检查、Xray 检测或采集。
- 订阅访问事件只保存 IP 哈希和简化事件统计；超过 5/10/30 个活跃 IP 哈希时只标记风险，不直接硬封，避免误伤正常用户。
- 订阅缓存文件保存在 `SUB_CACHE_DIR`，属于运行数据，禁止提交 GitHub；缓存内容可能包含完整节点链接，必须和数据库、节点包、运行日志一样保护。
- 订阅到期后返回 HTTP 200 中文提示，引导用户查看最新 YouTube 视频获取新一期订阅；不要返回 500、堆栈、数据库错误或系统路径。
- 订阅活动反馈只收集必要字段，不要求手机号、邮箱、真实姓名或 Telegram 账号；IP 使用哈希/脱敏思路，不在公开页面显示。
- Telegram Bot 第一版只读取 `GET /api/public/current-claim` 返回当前领取页链接，不直接发高质量订阅链接，也不验证口令。
- 免费节点风险提示必须保留：不承诺 100% 可用、永久可用、高速稳定或所有地区/客户端都可用。

## 2026-05-24 Xray 队列检测安全补充

- Xray 全量检测采用队列模式，每批默认 50 条，低并发执行，不会一次性高并发跑完整候选池。
- 暂停/停止请求会在当前批次结束后生效，避免直接杀掉正在清理临时目录的检测进程；已完成结果会立即写入数据库。
- 队列只选择候选节点中的未检测节点，默认不重复检测已真实可用节点，也避免反复消耗 VPS 资源。
- 临时 Xray 配置仍固定监听 `127.0.0.1` 随机本地端口，不监听 `0.0.0.0`，不暴露代理端口到公网。
- 前端只展示全量统计和脱敏状态，不展示完整节点链接、UUID、密码、临时配置、临时端口或真实文件路径。

## 2026-05-24 ZIP 分发安全边界

- 公开领取安全由领取页口令验证、批次状态、有效期、下载次数和 IP 限制负责，ZIP 文件本身不再加密。
- 取消 ZIP 加密是为了兼容 Windows、手机、浏览器自带解压和 Telegram 下载场景，避免加密 ZIP 被误判为乱码或损坏。
- ZIP 根目录只放英文 ASCII 文件名，不创建中文目录、随机目录或批次目录，避免跨平台文件名乱码。
- ZIP 内文本文件使用 UTF-8 编码；说明文件可以包含中文内容，但不包含后台来源、服务器路径、Token、日志或数据库信息。

## 2026-05-24 Xray-core 真检测安全补充

- Xray-core 真实检测已实现实际临时代理检测流程，但默认仍关闭，必须通过 `XRAY_REAL_TEST_ENABLED=true` 和 `XRAY_CORE_PATH` 显式启用。
- 临时 Xray 入站固定 `listen: 127.0.0.1`，端口来自 `XRAY_LOCAL_PORT_MIN` / `XRAY_LOCAL_PORT_MAX` 随机范围，禁止监听 `0.0.0.0`。
- 每个节点单独生成临时配置目录，测试结束后删除；测试完成后先正常关闭 Xray 进程，必要时强制结束，避免残留代理进程。
- 并发由 `XRAY_REAL_TEST_CONCURRENCY` 控制，默认 2，最大 5；单节点超时由 `XRAY_REAL_TEST_TIMEOUT_SECONDS` 控制，避免轻量 VPS 负载失控。
- 测试日志和公开接口不输出完整节点链接、UUID、密码、Reality 参数、临时配置内容、临时端口、Token、Cookie、Session 或真实文件路径。
- 当前第一阶段支持 VLESS、VMess、Trojan、Shadowsocks；Hysteria2、TUIC 和 sing-box 专属协议必须后续通过 sing-box 扩展，不能强行用 Xray 误测。

## Xray-core 真实检测安全边界

- Xray-core 真实检测默认关闭，必须显式配置 `XRAY_REAL_TEST_ENABLED=true` 和 `XRAY_CORE_PATH`。
- 默认并发限制为 2，最大不超过 5，避免轻量 VPS 负载失控。
- 设计目标是只监听 `127.0.0.1` 随机本地端口，禁止监听 `0.0.0.0`，禁止把 VPS 变成开放代理。
- 临时 Xray 配置、完整节点链接、UUID、密码、Reality 参数、临时端口和测试日志不得写入公开页面。
- 当前版本先落地安全骨架和入口，未配置 xray-core 时只记录跳过，不启动临时进程。
- 后续协议转换完成时必须继续保证超时关闭、异常进程清理、日志脱敏和低并发队列。

## 节点质量档位与自动化读取

- 默认档位：`high` 0-100ms、`premium` 100-200ms、`community` 200-300ms、`backup` 300ms 以上。
- 质量分档优先使用真实代理延迟；未完成真实检测时才回退基础延迟。
- 0-100ms 高质量包默认不允许 Hermes/OpenClaw 自动化读取，除非管理员手动开启自动化权限。
- 自动化接口只读，必须配置 `AUTOMATION_API_TOKEN` 后才能访问。
- 自动化接口只返回已发布、未过期、允许自动化调用的节点包，不返回完整节点池、后台敏感信息、数据库路径或 Token。
- `daily-summary` 使用固定模板，不调用 AI，不消耗大模型 Token。

## 标准节点包文件

- `nodes.txt` 是主格式，一行一个纯节点链接，不包含来源、日志、后台备注、数据库 ID 或服务器路径。
- `clash.yaml` 与 `sing-box.json` 当前作为安全模板，后续继续完善真实转换。
- `README.txt` 只写使用说明、推荐客户端和免费节点时效性提示，不写后台敏感信息。

## 后台反馈处理安全

- 粉丝反馈仍然只能通过公开领取页提交必要字段，公开接口不会返回后台批次详情、节点内容、文件路径或统计明细。
- 后台处理反馈必须登录后调用 `PATCH /api/feedback/:id`。
- 反馈处理状态只允许固定枚举，避免任意状态污染后台数据。
- 处理备注限制为 200 字，后续如开放备注编辑仍需继续做长度限制和脱敏展示。
- 录屏模式下反馈页应隐藏可能暴露用户身份或环境的完整 IP、User-Agent、详细路径和敏感备注内容。

## 公开领取端安全架构

- 后台管理端和粉丝公开领取端在代码层面分离。
- 后台接口仍然必须登录，不能为了领取页方便关闭 `requireAdmin`。
- 节点包生成后默认是 `draft`，不会公开；只有管理员手动发布后才变为 `published`。
- 发布新批次会把旧 `published` 批次改成 `replaced`，避免公开领取页出现多个包。
- 公开领取页路径使用随机 slug：`/r/{batchSlug}`，禁止用自增 ID。
- 公开 API 使用 `/api/public/claim/:slug`，只返回标题、说明、有效期和解锁状态。
- 公开 API 禁止返回节点数量、节点来源、采集来源、测试结果、后台统计、文件路径、数据库路径、服务器路径、管理员信息和完整节点内容。
- 下载必须走后端受控接口：`/api/public/claim/:slug/download`，不能暴露真实 zip 文件路径。
- 下载接口会验证批次是否 `published`、是否过期、是否已解锁、总下载次数、单 IP 下载次数和文件路径边界。
- 公开领取页和公开 API 设置 noindex 相关标记，降低被搜索引擎索引的概率。

## 有效期、下载限制与渠道统计

- 每个批次可以设置有效期；过期批次会自动转为 `expired` 并停止领取。
- 每个批次可以设置总下载次数上限。
- 每个批次可以设置单 IP 下载次数上限。
- 每个批次可以设置错误口令次数上限，连续错误后临时冻结。
- `from` 参数用于渠道统计，例如 `/r/slug?from=youtube`、`/r/slug?from=telegram`。
- 渠道统计只记录来源平台、访问、口令输入、口令正确/错误和下载次数，不保存明文 IP。

## 反馈入口隐私与防刷

- 公开领取页反馈入口只收集能否使用、设备系统、客户端软件、问题类型和可选备注。
- 不要求粉丝填写手机号、邮箱、真实姓名、Telegram 账号或详细地址。
- 反馈备注限制为 200 字。
- 问题类型使用固定枚举，避免任意字段污染后台统计。
- 反馈自动关联批次和 `from` 渠道，不需要粉丝手动填写批次信息。
- IP 仍按 HMAC 哈希记录在公开事件中，不保存明文 IP。
- 录屏模式下反馈备注、渠道链接、slug、路径和日志内容需要继续脱敏展示。

## 未来域名与端口隐藏规划

- 当前版本不配置证书，不修改 80/443，不影响 X-UI。
- 后续可以用 Cloudflare Tunnel、Caddy 或 Nginx 将后台域名和领取域名分开。
- 推荐后台域名：`admin.huage.us` 或 `panel.huage.us`。
- 推荐公开领取域名：`get.huage.us/r/{slug}` 或 `node.huage.us/r/{slug}`。
- 公开领取域名未来应只允许访问 `/r/:slug` 和 `/api/public/claim/:slug` 相关接口。

## 后台登录安全

- 管理后台必须登录后访问。
- 首次管理员账号由 `.env` 设置。
- 数据库已有管理员后，不再使用环境变量覆盖密码。
- 密码使用 bcrypt 哈希存储，不能明文保存。
- 登录失败次数达到阈值后会临时锁定。
- Session 使用 HttpOnly Cookie，支持过期。

## `.env` 安全

- 真实 `.env` 禁止提交到 GitHub。
- 生产环境必须更换默认密码和 `SESSION_SECRET`。
- `.env.example` 只能保存模板值。

## GitHub 禁止提交内容

禁止提交：

- 真实 `.env`
- Token、API Key、账号密码
- SQLite 数据库
- 采集到的节点
- 测试通过的节点
- 订阅文件
- 节点包和 zip 文件
- 运行日志
- 领取统计和反馈数据
- 真实后台配置

允许提交：

- 源码
- README 和 docs 文档
- Docker Compose 配置模板
- `.env.example`
- `.gitignore`

## 节点数据保护

- 节点内容只保存在 VPS 运行数据库中。
- 导出的节点包只保存在运行数据目录。
- GitHub 仓库只保存软件开发文件，不保存运行数据。

## 日志脱敏

后续版本必须保证日志不输出：

- 完整节点链接
- 完整 IP
- UUID
- 密码
- Token
- 私密来源 URL
- 管理员账号密码

## 公开视频模式

v0.6.0 已实现后端设置和基础脱敏：

- 前端开关会保存到后端 `app_settings.public_video_mode`。
- 前端隐藏管理员账号。
- 节点池接口隐藏来源 URL，并脱敏失败原因。
- 来源缓存接口隐藏来源 URL，并脱敏错误信息。
- 日志接口会脱敏节点链接、Token、UUID 和完整 IPv4。
- 领取页事件 IP 只保存 HMAC 哈希，不保存明文 IP。

仍需在 v1.0.0 前继续检查所有新增页面，确保录屏时不出现服务器路径、Token、完整节点、完整 IP、UUID、密码或敏感来源。

## 采集限速

v0.2.0 已加入基础限制：

- `COLLECT_MAX_CONCURRENCY` 控制并发，默认 2。
- `COLLECT_DAILY_MAX_RUNS` 控制每日最大采集次数，默认 6。
- `COLLECT_MIN_INTERVAL_MINUTES` 控制同一来源重复访问间隔，默认 60 分钟。
- `HTTP_TIMEOUT_SECONDS` 控制请求超时。
- `COLLECT_MAX_BYTES` 控制单个来源最大读取大小。
- 失败来源会进入更长冷却时间。

采集功能必须继续遵守：

- 只采集公开内容
- 不访问私人仓库
- 不绕过登录
- 不抓取私人数据
- 不高频请求
- 不全网乱扫
- 限制并发
- 失败重试有限
- 失败来源自动降频
- 缓存已发现来源

## 下载限速

v0.6.0 已为公开下载接口加入分钟级限速。公开领取页仍需继续遵守：

- 限制下载频率
- 记录下载事件
- 防止同一来源短时间大量请求
- 不直接展示完整节点
- 只有口令正确后才能下载加密 zip 包

## VPS 流量安全

系统本质是公开资源整理和基础初筛，不是公开代理服务：

- 不开放代理端口给公网
- 测试相关临时服务只允许绑定 `127.0.0.1`
- 测试完成后关闭临时进程
- 不做大流量压测
- 不上传节点到 GitHub

v0.3.0 的基础测试只发起出站 TCP 连接，不启动代理服务，不监听公网端口。后续如引入更完整的协议测试，仍必须保持本地绑定、限速和测试后清理。

## 节点包导出安全

v0.4.0 已实现导出批次和 zip 包生成：

- 导出包保存在运行数据目录 `/data/exports`，不得提交 GitHub。
- zip 口令由管理员手动设置。
- 数据库存储口令哈希，不保存明文口令。
- `export_options_json` 会移除口令后再保存。
- 纯节点文本只包含一行一个节点，不附加后台延迟、来源、状态或备注。
- v0.5.0 已开放公开下载接口，必须先通过口令验证才能下载。
- 领取页不会直接展示完整节点。
- 下载事件和反馈事件会写入数据库统计。
- IP 只保存 HMAC 哈希，不保存明文 IP。
