# v1.1.11 subscription-import-parser

日期：2026-06-12

## 范围声明

- 本次没有修改 VPS 部署配置。
- 本次没有修改 data/logs/.env/docker-compose.yml。
- 本次没有修改 Caddy/DNS/HTTPS。
- 本次没有修改 tools/xray/**。
- 本次没有绕过发布池。
- Bot 仍然只从 publish_subscription_pool 发放。
- 真实测试订阅 URL 没有写入源码、测试和任务日志。

## 改动摘要

1. 后台手动导入有效节点支持原始节点 URI、Base64 订阅内容和 http/https 订阅 URL。
2. 订阅 URL 拉取后会自动识别 Base64 内容或原始节点列表，并提取 vmess/vless/trojan/ss/ssr 节点。
3. Base64 支持普通 Base64、URL-safe Base64、缺少 padding 和多行文本。
4. 导入统计新增 subscription_url_count、base64_decoded_count、extracted_count。
5. 导入结果只写入有效节点库，manual_cf 和 Base64/URL 导入都不会自动进入 publish_subscription_pool。
6. 后台页面导入提示和结果文案已更新。

## SSRF 防护

- 只允许 http/https。
- 拒绝 localhost、127.0.0.1、0.0.0.0、::1。
- 拒绝内网、链路本地、保留地址、云元数据地址。
- URL 请求超时 10 秒。
- 单个订阅 URL 最大读取 2MB。
- 最多跟随 3 次重定向，且每次重定向都会重新校验目标地址。

## 脱敏规则

- 日志只记录导入统计，不记录完整订阅 URL。
- 错误详情中的 URL 会隐藏 token/key/secret 等敏感 query。
- 普通列表接口不返回完整节点 URI，完整 URI 仍只通过后台复制接口返回。

## 发布规则

- 订阅 URL 导入只是解析节点，不等于自动发布。
- Base64 导入只是解析节点，不等于自动发布。
- manual_cf 节点仍然不自动发布。
- 管理员仍需复制节点、本地测试，再手动点击“标记可发布”。
- Bot 仍然只从 publish_subscription_pool 发放。
