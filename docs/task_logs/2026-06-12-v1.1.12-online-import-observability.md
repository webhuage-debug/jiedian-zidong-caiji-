## 改动摘要

1. 保持 v1.1.11 的原始 URI、Base64 文本、http/https 订阅 URL 导入能力不变。
2. 新增 manual_import_logs 表，记录每次后台手动导入的脱敏统计。
3. 导入记录包含：
   - 导入时间
   - 输入来源类型：raw_uri / base64_text / subscription_url / mixed
   - 订阅 URL 数
   - Base64 解码数
   - 提取节点总数
   - 新增有效节点数
   - 重复节点数
   - 失败数量
   - 错误摘要
4. 错误摘要只保存分类原因，不保存完整 token 或完整敏感 URL。
5. 后台有效节点页新增“最近导入记录”展示区，按最新优先展示。
6. manual_cf、Base64、订阅 URL 导入后仍只进入有效节点库，不自动进入发布池。

## 安全说明

- SSRF 防护、URL 脱敏和 token 不入日志的逻辑保持不变。
- 普通列表接口仍不返回完整节点 URI。
- 完整节点 URI 仍只通过登录后台的复制接口返回。
- 导入记录不保存完整输入内容。
