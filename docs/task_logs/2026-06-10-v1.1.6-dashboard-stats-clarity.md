# v1.1.6 Dashboard Stats Clarity

Date: 2026-06-10
Branch: codex/v1.1.6-dashboard-stats-clarity

## Scope

This release only clarifies dashboard node-count wording and API count fields.

## Changes

- Added explicit database stats fields:
  - `asset_nodes`: pending + valid + current invalid table rows.
  - `current_inventory_nodes`: pending + valid nodes.
  - `historical_invalid_nodes`: cumulative invalid/pruned counter.
- Updated dashboard summary labels so "节点库" is not confused with total historical collection.
- Changed the first dashboard number to "当前库存", meaning pending + valid.
- Kept final subscription filtering, collection, validation, Bot flow, Docker, deployment, and cache behavior unchanged.

## Safety

- Did not modify `data/`, `logs/`, `.env`, or `docker-compose.yml`.
- Did not modify VPS/Caddy/Nginx/DNS/HTTPS/Sub-Store/Bot claiming flow.
- No database migration is required; new stats fields are calculated from existing tables/counters.
