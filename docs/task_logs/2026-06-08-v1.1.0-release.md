# v1.1.0 Release Log

Date: 2026-06-08

## Release Branch And Tag

- Branch: `codex/v1.1.0-release`
- Tag: `v1.1.0`
- Remote repository: `https://github.com/webhuage-debug/jiedian-zidong-caiji-.git`

## Main Changes

- Added default subscription publish-region filtering.
- Subscription pool now prefers Asia nodes first, then US nodes.
- Europe, Africa, and unknown-region nodes are excluded from the default subscription pool without deleting them from the database.
- Added keyword-based fallback region detection from node URI, remarks, fragments, hostnames, and VMess metadata.
- Added tests for region detection and subscription-pool filtering.

## Acceptance Evidence

- Full unit test suite passed: 90 tests.
- Syntax check passed for `node_region.py`, `node_database.py`, and `web_app.py`.
- Real acceptance smoke passed with 5 successful claim rounds and 20 nodes returned per subscription.
- Incremental collection added 200 pending nodes during live testing.
- Xray validation produced 5 new valid nodes during live testing.
- Final subscription conversion check passed for V2RayNG, Shadowrocket, Sing-box, Clash Verge, and Surge.

## Notes

- No Docker, deployment, Nginx, Telegram Bot main flow, runtime data, logs, or environment files were changed.
- Free nodes are still best-effort backup nodes; this release improves default region selection, not a 100% availability guarantee.
