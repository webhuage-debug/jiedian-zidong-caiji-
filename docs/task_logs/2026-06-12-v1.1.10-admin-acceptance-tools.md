# v1.1.10 后台验收工具轻量增强

日期：2026-06-12

## 范围声明

- 本次没有修改 VPS / Caddy / DNS / HTTPS / systemd 配置。
- 本次没有修改 data/logs/.env/docker-compose.yml。
- 本次没有修改 tools/xray。
- 本次没有接入 Cloudflare API，没有自动部署 CF Worker，没有自动生成 CF 节点。
- Bot 发放逻辑保持只读 publish_subscription_pool。

## 改动摘要

1. 有效节点页新增分组筛选：默认可用、全部、自建CF、手动普通、GitHub公开、CF候选、已发布、未发布、已禁用。
2. 手动导入支持 source_type 选择：
   - manual_normal：手动普通
   - manual_cf：自建CF
3. manual_cf 导入会标记 manual_added=1、source_type=manual_cf、cf_candidate=1，但不会自动进入发布池。
4. 新增复制节点接口，支持单个复制和按当前筛选批量复制。
5. 页面列表不直接明文展示完整 URI，完整 URI 只通过登录后台的复制接口返回。
6. 禁用节点默认不允许复制。
7. 已发布节点卡片高亮显示，禁用节点置灰显示。
8. 已发布节点不再显示普通“标记可发布”按钮，只显示“移出发布池”。

## 接口

- POST /api/valid-nodes/copy
  - 支持 uri 单个复制
  - 支持 protocol、country、group、limit 批量复制
  - 返回 content 为一行一个节点 URI
  - 不返回已禁用节点

- POST /api/valid-nodes/manual-import
  - 新增 source_type 参数
  - manual_cf 不会自动发布
