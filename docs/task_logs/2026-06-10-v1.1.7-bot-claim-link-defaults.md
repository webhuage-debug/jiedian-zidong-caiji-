# v1.1.7 Bot Claim Link Defaults

Date: 2026-06-10
Branch: codex/v1.1.7-bot-claim-link-defaults

## Scope

This release only fixes Telegram Bot claim-entry defaults and visibility.

## Changes

- Normalizes Bot usernames from `@name`, `name`, `https://t.me/name`, or `https://telegram.me/name`.
- Exposes the generated Telegram private claim URL in Bot config as `bot_private_start_url`.
- Exposes `claim_entry_ok` and `claim_entry_reason` so the dashboard can show whether group buttons can open Telegram private chat.
- When the Bot process has a token but no username, it calls Telegram `getMe` once during runtime and saves the returned username.
- Dashboard Bot page shows the current group-button claim entry status.

## Safety

- Did not modify deployment, Docker, reverse proxy, DNS, HTTPS, Sub-Store, data files, logs, or Telegram claim flow logic.
- Did not change subscription output filtering or validation behavior.
- No database migration is required; username normalization uses existing Bot config storage.
