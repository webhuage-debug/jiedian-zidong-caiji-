# v1.1.14 Publish Control Center

## Scope

- Added a backend publish control center view for layered node operations.
- Added summary, published, and ready-to-publish API data sources.
- Added a dashboard section on the valid nodes page to separate:
  - currently published nodes
  - ready-to-publish candidates
  - valid inventory
  - manual CF nodes
  - GitHub public nodes
  - CF candidates
  - disabled / blocked nodes

## Safety Notes

- This release did not modify VPS deployment configuration.
- This release did not modify `data/`, `logs/`, `.env`, or `docker-compose.yml`.
- This release did not modify Caddy, DNS, HTTPS, Nginx, or systemd configuration.
- This release did not modify `tools/xray/**`.
- This release did not modify the Bot delivery source.
- Bot delivery still reads only from `publish_subscription_pool`.
- `/sub/<token>` still exports only from `publish_subscription_pool`.
- This release only improves the admin publish management view and does not change delivery rules.

## Backend Changes

- Added `NodeDatabase.publish_center_summary()`.
- Added `NodeDatabase.publish_center_published()`.
- Added `NodeDatabase.publish_center_ready()`.
- Added read-only API endpoints:
  - `GET /api/publish-center/summary`
  - `GET /api/publish-center/published`
  - `GET /api/publish-center/ready`

## UI Changes

- Added a publish center section to the valid nodes page.
- Added top summary cards for current publish and inventory layers.
- Added a dedicated "currently published" list backed by `publish_subscription_pool`.
- Added a dedicated "ready to publish" list backed by unpublished premium candidates and unpublished manual CF nodes.
- Existing manual import, copy, publish, unpublish, disable, and delete actions remain available.

## Tests

- Added database tests for publish center summary, published list, and ready list.
- Added web route tests for the publish center API endpoints.
