# v1.1.4 dashboard readability cleanup

Date: 2026-06-10

## Scope

Small dashboard usability update. No collector, validator, subscription generation, Docker, deployment, reverse proxy, database, data, logs, `.env`, or Telegram Bot flow changes.

## Changes

- Bumped visible app version to `v1.1.4`.
- Added a first-screen dashboard summary above the automatic control panel.
- Surfaced the key numbers directly:
  - total node library
  - pending validation nodes
  - valid nodes
  - premium subscription pool
  - estimated subscription output
  - invalid / pruned nodes
  - subscription links
  - conversion cache rows
- Added simple status cards for auto control, collector, validator, and Bot.
- Added dashboard quick actions that call the existing buttons / APIs:
  - start collector
  - start validator
  - recheck valid nodes
  - clear conversion cache
  - stop collector / validator
- Collapsed the automatic control parameter block by default.
- Hid the old cockpit gauges and 7-day trend chart from the dashboard first screen. The underlying stats code and APIs are unchanged.

## Risk

- This is a frontend readability change. Existing backend counters remain unchanged.
- The dashboard "estimated output" is computed from the current export limit and premium / valid node counts; the exact final subscription count is still determined by the subscription output path.
