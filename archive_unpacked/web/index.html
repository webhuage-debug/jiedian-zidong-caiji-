VALID NODE PROCESSING

              
有效节点处理

              
这里是导出前的临时整理区域：只在导出 Base64 订阅时改名，不修改数据库里的有效节点原始 URI。

            

            
          

          

            
            
          

          

            
{country_name}根据出口 IP 匹配的中文国家名，例如 美国、德国。

            
{country}国家代码，例如 US、DE；多出口国家会显示 DE,FR。

            
{protocol}协议大写名，例如 VLESS、VMESS、SS。

            
{protocol_lower}协议小写名，例如 vless、vmess。

            
{validated_date}最后验证日期，例如 2026-06-02。

            
{validated_at}最后验证完整时间。

            
{date}本次导出日期。

            
{index}三位序号，例如 001、002。

            
{proxy_ip}第一个出口 IP。

            
{proxy_ips}全部出口 IP。

            
{latency}验证耗时秒数，保留两位小数。
